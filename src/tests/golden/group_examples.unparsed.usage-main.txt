usage: flap_test_group_examples  [--string value] {gwe,gne} ...

group examples usage FLAP example


Optional switches:
   --string value, -s value
    default value test
    String input

Commands:
  gwe
          Group with examples
  gne
          Group without examples

For more detailed commands help try:
  flap_test_group_examples gwe -h,--help
  flap_test_group_examples gne -h,--help

Examples:
   flap_test_group_examples -s 'test string'
   flap_test_group_examples --string 'test string'
